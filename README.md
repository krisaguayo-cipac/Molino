Molino - GitHub Pages site

This repository contains a minimal Jekyll starter site for molino.digital. The site is built by GitHub Pages from the repository root.

To modify the site, edit the files in the repository and push changes. GitHub Pages will rebuild the site automatically.

DNS: Add A records for the apex (molino.digital) pointing to GitHub Pages IPs, or use an ALIAS/ANAME if your DNS provider supports it. If you prefer to serve from www, set a CNAME for www to krisaguayo-cipac.github.io and optionally redirect the apex to www.
